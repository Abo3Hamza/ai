# 🎮 لعبة بطاقات الذاكرة (Memory Card Game)

لعبة تفاعلية وممتعة لاختبار وتحسين مهارات الذاكرة لديك!

## ✨ المميزات

- **أكثر من 50 خلية**: اختر من ثلاثة مستويات صعوبة
  - 🟢 سهل: 26 بطاقة
  - 🟡 متوسط: 50 بطاقة (الافتراضي)
  - 🔴 صعب: 60 بطاقة

- **⏱️ عداد الوقت**: يبدأ تلقائياً عند النقر على أول بطاقة

- **❌ عداد الحركات الخاطئة**: يحسب عدد المرات التي لم تتطابق فيها البطاقات

- **✅ عداد الأزواج المطابقة**: يعرض عدد الأزواج التي وجدتها بنجاح

- **🎨 تصميم احترافي**: واجهة جميلة وسلسة مع دعم الأجهزة المحمولة

- **🍎 رموز متنوعة**: فواكه، خضروات، طعام، وغيرها

## 🎮 كيفية اللعب

1. اختر مستوى الصعوبة من القائمة المنسدلة
2. انقر على "ابدأ اللعبة" 🎮
3. ابدأ بالنقر على البطاقات لإيجاد الأزواج المتطابقة
4. كل زوج صحيح يبقى مكشوفاً بلون أخضر
5. استمر حتى تطابق جميع الأزواج وستظهر رسالة تهنئة

## 🛠️ التكنولوجيا المستخدمة

- **HTML5**: لهيكل الصفحة
- **CSS3**: للتصميم والتأثيرات البصرية
- **JavaScript**: لمنطق اللعبة والتفاعل

## 📦 التثبيت والتطوير

```bash
# تثبيت المتطلبات
pnpm install

# تشغيل خادم التطوير
pnpm dev

# بناء للإنتاج
pnpm build
```
